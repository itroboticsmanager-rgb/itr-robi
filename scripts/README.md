## enable-ssh

`enable-ssh.cmd` + `enable-ssh.ps1` — провізіонінг пристрою: вмикають OpenSSH-сервер,
додають ключ керуючої станції, відкривають порт і друкують IP та ім'я користувача.

Навіщо: у планшета немає фізичної клавіатури, а набирати ці команди сенсорною —
довго й з помилками. Обидва файли кладуться на ту саму флешку, з якої ставилася
система; на пристрої запускається `.cmd`, він сам просить підвищення прав
(одне торкання UAC) і виконує решту.

Ключ у скрипті **публічний** і секретом не є. Приватний лежить лише на керуючій
станції. Щоб довірити іншу машину, замініть рядок `$key` її публічним ключем.

Процедура цілком — [docs/provisioning.md](../docs/provisioning.md).

## kiosk

`kiosk/install-kiosk.ps1` (від адміністратора) + `kiosk/robi-kiosk.ps1` (наглядач,
працює в сесії `Robi`) — kiosk-режим планшета (`D-064`): завдання Планувальника при
вході, служба + Edge `--kiosk` з перезапуском, політики проти сповіщень і свайпів,
пауза для обслуговування файлом `C:\ROBI\kiosk\pause`. Обидва файли навмисно в ASCII:
Windows PowerShell 5.1 читає `.ps1` без BOM як ANSI.

Перевірка без браузера на робочому ПК:

```powershell
scripts/kiosk/robi-kiosk.ps1 -ConfigPath <тека>\kiosk.json -NoBrowser -RunSeconds 60
```

Деталі — [docs/provisioning.md](../docs/provisioning.md), крок 7.3.
