# Electronics

- `schematics/` — схеми живлення, сигналів і модулів.
- `pcb/` — вихідні файли власної плати, якщо вона буде потрібна.
- `wiring/` — таблиці кабелів, роз'ємів, довжин і фото складання.

Не створюйте остаточні посадочні місця чи кабелі до підтвердження точних моделей компонентів. Чернетка складу системи наведена в `../../docs/hardware.md` і `../../docs/bom.md`.
