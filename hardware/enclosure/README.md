# Enclosure

- `cad/` — параметричні вихідні CAD-файли.
- `exports/` — контрольовані STEP/STL/3MF-експорти для ревізій.
- `print-profiles/` — профілі слайсера та примітки для конкретного принтера/PLA.

Усі поточні розміри є стартовими припущеннями. Перед моделюванням потрібні реальні компоненти або офіційні механічні креслення; див. `../../docs/enclosure.md`.
