# ROBI — привітання

`robi_greeting.blend` містить окрему анімацію на основі виправленого ROBI Sport.
Нейтральна модель лишається у `robi_sport_neutral.blend`.

6 секунд, 30 кадрів/с, кадри 1–180. Action:
`ROBI • Friendly greeting • 6 seconds`.

Робі піднімає ліву руку, повертає долоню до глядача, м’яко махає,
усміхається та повертається в нейтральний стан. Є невеликі рухи тулуба,
голови й антени, два моргання. Стопи й таз залишаються нерухомими.

Для перегляду відкрийте файл у Blender і натисніть Space над Timeline.
На шкалі часу є позначки фаз жесту. Кадр 181 дублює нейтральну позу
для стику; у відео експортуються кадри 1–180.

Рух записано в ключі FK-кісток. Міміка керується властивостями рига
`smile`, `blink_L/R`, `look_x/z`; драйвери матеріалу не потребують Python
під час відтворення. Початкова й кінцева міміка нейтральні.

Джерело: `scripts/blender/animate_robi_greeting.py`.
Перевірка: `scripts/blender/validate_robi_greeting.py`.
Рендер: `scripts/blender/render_robi_greeting.py --animation`.
Результати: `out/robi-greeting/`.

Генератор анімації запускається на нейтральній моделі й створює окремий файл.
MP4: `out/robi-greeting/robi-greeting.mp4`, 960 × 960, H.264, 30 кадрів/с.
