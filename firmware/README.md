# Firmware

Місце для прошивок допоміжних мікроконтролерів, якщо окремий контролер буде потрібний для сервоприводів, RGB, живлення або реального часу.

Поточне припущення: Raspberry Pi керує прототипом напряму або через готовий драйвер. Рішення про окремий MCU не ухвалено.
