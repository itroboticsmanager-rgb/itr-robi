# Кіоск ROBI · Three.js

Верхнє вікно завжди показує 3D-логотип ITRobotics. Робі іноді визирає,
роздивляється відвідувача або вітається. Повноекранної майстерні немає.

## Локальний перегляд

З кореня репозиторію:

```powershell
./scripts/preview-kiosk.ps1
```

Скрипт збирає клієнт і запускає локальну Python-службу на порту 4174 з
прикладом контенту, без CRM та камери. Відкрити http://127.0.0.1:4174/.
Конфіг і журнали лежать в `artifacts/kiosk-preview/`. Для іншого порту
передати `-Port 4175`. Зайнятий порт не перезапускається автоматично.

Для розробки клієнта:

```powershell
cd prototypes/robi-room
npm ci
npm run dev
```

Адреса http://127.0.0.1:4173/ показує сцену; без Python-служби меню відсутнє.
`/logo.html` дає окремий перегляд двох пропорцій із вибором сценки, паузою
та повзунком для перевірки ключових поз. Ця сторінка призначена для розробки.

## Поведінка

- Синє тло, чіткі кольори SVG, тонкий рельєф дрібних деталей. Колеса
  обертаються, по літерах проходить коротка хвиля, маленький робот над
  знаком нахиляється. Нижній напис залишається нерухомим.
- Робі з’являється на 11–15 секунд; паузи між появами тривають 55–90 секунди.
- П’ять варіантів: двоетапно визирнути, привітатися, роздивитися,
  з’явитися з-за бокового краю, сховатися й повернутися («ку-ку»). Рухи очей, голови,
  корпуса й долоні розведені в часі. Вхід і вихід плавні.
- Натискання на видимого Робі запускає коротке привітання. Дотик під час
  виходу не змінює траєкторії. Сцена не розгортається від натискання або свайпу.
- «Менше руху» й системна настройка залишають статичне лого та зупиняють
  анімацію. Локальна настройка зберігається між відкриттями.
- Меню, картки та QR використовують наявну Python-службу.
- Поза екраном, у фоновій вкладці та поверх меню 3D-рендер призупиняється.
- Якщо WebGL недоступний, відображається локальний SVG-логотип.

## Код і перевірка

`src/main.js` з’єднує сцену з кіоском. `logostage.js` відповідає за камеру,
світло, рендер і кадрування. `cameo.js` задає появи та плавні пози.
`logo.js` будує знак із локального SVG, `robot.js` містить модель і її риг.
`kiosk.js` керує меню, банерами й QR. Старі модулі майстерні не імпортуються
головним клієнтом і залишені як окремі напрацювання.

```powershell
npm test
npm run build
```

`tests/cameo.test.js` перевіряє безперервність, переривання, паузи та
незалежність від частоти кадрів. Python-тест перевіряє, що вилучена команда
`workshop` не відкриває маскота. `?debug` додає прихований
`output#robi-diagnostics` із FPS, поточною сценкою та лічильниками рендера.

Один WebGL-контекст, DPR до 2, requestAnimationFrame без штучного ліміту
30 FPS. Усі ресурси локальні. Замір у браузері ноутбука не замінює перевірку
нагрівання та тривалої роботи на фізичному Surface Go 2.


Логотип закріплений у просторі: загального погойдування та плавання немає.
Статичний невеликий нахил залишає видимим рельєф. Ортографічна камера
зберігає пропорції Робі по всій ширині вікна. Поява рухає персонажа цілком,
без анімації масштабу; різні входи перевірені зліва й справа. Тест
`stage-camera.test.js` звіряє проєкцію справжньої голови в центрі та біля
країв на трьох пропорціях екрана.
